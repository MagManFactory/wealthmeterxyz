What this section is for

Wealth Briefs is not a set of made-up advice cards. It is a source shelf. Each card gives you the topic, the source, and a short plain-language note on why that source matters. If you want the original argument, data, or method, open the linked paper, report, or book listing.

Simple on purpose The card text avoids technical language where possible. It is there to help you sort sources quickly, not replace them.
Real entries only Every card is tied to a row in the master source file and keeps the original title, publication, year, and link.
Useful for follow-up work This page is a starting point for deeper analysis, calculators, and future longform pieces.

Evidence policy

Only real sources Every entry has to point to a real paper, report, scorecard, or book before it appears on the shelf.
Source types stay visible You can see whether you are opening a journal paper, working paper, report, scorecard, or book before you click.
Books are context, not final proof Books can frame a topic well, but they should not carry the same evidentiary weight as a paper or scorecard on their own.
